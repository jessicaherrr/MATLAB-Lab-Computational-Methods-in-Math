# MATLAB Lab: Computational Methods in Mathematics

This repository contains my MATLAB programming exercises and laboratory work for **MAT 2010: Computational Methods in Mathematics** at California State Polytechnic University, Pomona.

## Course Purpose

This course develops foundational programming and computational problem-solving skills using MATLAB. It emphasizes translating mathematical ideas into clear algorithms and implementing them with correct MATLAB syntax.

The repository also serves as preparation for future coursework in:

* Numerical Analysis
* Optimization
* Quantitative Modeling
* Data Science and Machine Learning

## Topics Covered

The course progresses from basic MATLAB syntax to more advanced computational methods:

1. Variables, expressions, and operators
2. Random-number generation
3. Characters and relational expressions
4. MATLAB functions
5. Vectors and matrices
6. Anonymous functions and plotting
7. Conditional statements
8. `for` loops and sorting algorithms
9. `while` loops
10. Monte Carlo methods
11. Recursive algorithms
12. Keyboard input and screen output


## Long-Term Goal

The long-term goal of this repository is to build a strong connection between mathematical theory, algorithm design, and computational implementation. These skills will support future study and projects in numerical analysis, quantitative finance, data science, and scientific computing.

## Academic Integrity

This repository documents my own learning process and original work. The materials are intended for personal study, review, and portfolio documentation. They should not be copied or submitted by other students as their own coursework.
